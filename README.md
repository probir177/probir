# FTP এআই অ্যাসিস্ট্যান্ট

মোবাইল/অ্যাড নেটওয়ার্ক স্টোরের FTP সার্ভারের সাথে যুক্ত একটি ওয়েবসাইট-ভিত্তিক এআই অ্যাসিস্ট্যান্ট। বাংলায় নির্দেশ দিলে Claude নিজে থেকেই FTP-তে ফাইল খোঁজা, পড়া, বিশ্লেষণ, লেখা, নাম বদলানো ও মোছার কাজ করে।

## বৈশিষ্ট্য

- **এআই চ্যাট (বাংলা):** যেমন "`/reports` ফোল্ডারের সব CSV পড়ে এই মাসের মোট আয় হিসাব করে `summary.txt`-এ লেখো"
- **সম্পূর্ণ অটোমেশন:** এআই একাধিক ধাপ নিজেই পরিকল্পনা করে সম্পন্ন করে (এক অনুরোধে সর্বোচ্চ ২৫ ধাপ)
- **নিরাপত্তা সুইচ:** "সম্পূর্ণ অটোমেশন" বন্ধ থাকলে ফাইল লেখা, নাম বদলানো ও মোছার আগে স্ক্রিনে অনুমতি চাইবে। চালু করলে কিছু জিজ্ঞেস না করেই সব করবে।
- **যেসব ফাইল পড়তে পারে:**
  - টেক্সট — CSV, TXT, JSON, HTML, লগ (সর্বোচ্চ 512KB)
  - Excel — `.xlsx`, `.xls`, `.xlsm`, `.xlsb`, `.ods` (সর্বোচ্চ 20MB)। সব শিট টেবিল আকারে পড়ে, তারিখ `2026-11-01` রূপে দেখায়।
  - Word — `.docx`, `.docm`, `.doc` (সর্বোচ্চ 20MB)। `.docx` থেকে শিরোনাম, তালিকা, টেবিল এবং ভেতরের ছবি (সর্বোচ্চ ৮টি) দেখে। পুরোনো `.doc` থেকে শুধু লেখা, হেডার-ফুটার ও ফুটনোট পায়।
  - PDF — সর্বোচ্চ 25MB। লেখা, টেবিল, এমনকি স্ক্যান করা পাতাও পড়তে পারে।
  - ছবি — `.jpg`, `.png`, `.webp`, `.gif`, `.bmp`, `.tiff`, `.avif` (সর্বোচ্চ 20MB)। ব্যানার, রসিদ, স্ক্রিনশটের লেখা ও বিষয়বস্তু বোঝে। বড় ছবি খরচ কমাতে নিজে থেকেই ছোট করে নেয়।
- **F-Droid সংযোগ:** প্রায় ৫,০০০ ওপেন-সোর্স অ্যান্ড্রয়েড অ্যাপ খোঁজা ও তুলনা করা যায়। যাচাই করা APK সরাসরি দোকানের FTP-তে রাখা যায়। প্রোগ্রামিংয়ের সময় অ্যাপগুলোর সোর্স কোড ও বিল্ড রেসিপি দেখা যায়। বিস্তারিত ও রোডম্যাপ: [docs/FDROID.md](docs/FDROID.md)
- **দোকানের অ্যাপ লাইব্রেরি:** FTP-র `/apps`-এ থাকা APK-গুলোর নতুন ভার্সন খুঁজে নিজে থেকেই হালনাগাদ করে, প্রয়োজনে প্রতি রাতে। পুরোনো ভার্সন `_old`-এ রেখে দেয়, আর গ্রাহকদের জন্য বাংলায় `catalog.html` বানায়।
- **ফাইল ব্রাউজার:** ফোল্ডার দেখা, ডাউনলোড, আপলোড
- **FTP / FTPS / SFTP:** `FTP_PROTOCOL=auto` দিলে সার্ভারের ধরন নিজেই খুঁজে নেয়
- **সুরক্ষা:** পাসওয়ার্ড লগইন, লগইনে রেট-লিমিট, CSRF সুরক্ষা, `FTP_ROOT`-এর বাইরে যাওয়া নিষেধ, রুট ফোল্ডার মোছা নিষেধ

## চালু করার নিয়ম

Node.js 20 বা তার নতুন সংস্করণ লাগবে।

```bash
npm install
cp .env.example .env      # তারপর .env ফাইলে নিজের তথ্য দিন
npm start                 # http://localhost:3000
```

`.env`-এ যা দিতে হবে:

| ভেরিয়েবল | কাজ |
|---|---|
| `ANTHROPIC_API_KEY` | Claude API কী ([platform.claude.com](https://platform.claude.com)) |
| `ADMIN_PASSWORD` | ওয়েবসাইটে লগইনের পাসওয়ার্ড |
| `SESSION_SECRET` | কমপক্ষে ৩২ অক্ষরের র‍্যান্ডম স্ট্রিং |
| `FTP_HOST`, `FTP_PORT`, `FTP_USER`, `FTP_PASSWORD` | FTP সার্ভারের তথ্য |
| `FTP_PROTOCOL` | `auto` / `ftp` / `ftps` / `sftp` |
| `FTP_ROOT` | এআই শুধু এই ফোল্ডারের ভেতরে কাজ করবে (ডিফল্ট `/`) |
| `CLAUDE_MODEL` | ঐচ্ছিক, ডিফল্ট `claude-opus-5-5` |

## হোস্টিং

যেকোনো Node.js হোস্টিং-এ চলবে (VPS, Render, Railway, Hostinger VPS ইত্যাদি)। ইন্টারনেটে খুলে দিলে অবশ্যই **HTTPS**-এর পেছনে চালান এবং `NODE_ENV=production` দিন।

## গঠন

```
src/server.js   ওয়েব সার্ভার, লগইন, API
src/agent.js    Claude এজেন্ট ও FTP টুলসমূহ
src/ftp.js      FTP/FTPS/SFTP সংযোগ
src/readers.js  Excel / Word / PDF / ছবি পড়ার উপযোগী করা
src/fdroid.js   F-Droid ইনডেক্স, খোঁজা, সোর্স কোড, APK ডাউনলোড
src/library.js  অ্যাপ লাইব্রেরি: আপডেট যাচাই, হালনাগাদ, ক্যাটালগ, রাতের স্বয়ংক্রিয় আপডেট
docs/FDROID.md  F-Droid সংযোগের বিবরণ ও রোডম্যাপ
public/         ওয়েব ইন্টারফেস
```

## সীমাবদ্ধতা

- কথোপকথন সার্ভারের মেমরিতে থাকে, তাই সার্ভার রিস্টার্ট হলে মুছে যায়।
- ZIP, PowerPoint ও পাসওয়ার্ড-সুরক্ষিত Word ফাইল এখনো পড়তে পারে না।
- একবার পড়া PDF বা ছবি পুরো কথোপকথনে থেকে যায়, তাই পরের প্রতিটি প্রশ্নে তার খরচ আবার যোগ হয়। অনেক বড় PDF পড়ার পর বিষয় বদলালে "নতুন কথোপকথন" চাপুন।
- ২০০,০০০ অক্ষরের বেশি বড় Excel ফাইলের শুরুর অংশটুকুই পড়ে। তখন এআই জানিয়ে দেবে যে বাকিটা দেখা হয়নি।
